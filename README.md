# 期权交易客户端 GUI 自动化

> 一款面向 Windows 期权交易客户端的自动化工具，帮你把**查询、下单、撤单、组合申报、一键开仓、设置检查**这些重复操作交给电脑。

---

## ✨ 能做什么

| 能力 | 说明 |
|---|---|
| 📊 **行情查询** | 统一查询驱动，批量获取行情数据并导出 |
| 📝 **自动下单** | 三键/四键/快速下单，支持 Excel 驱动批量操作 |
| ↩️ **批量撤单** | 一键全选撤单，无需手动逐笔操作 |
| 📦 **组合申报** | 拆分配方、组合申报全流程自动化 |
| 🎯 **超级策略** | 牛市/熊市、跨式/宽跨式 一键开仓 + 组合申报 |
| ⚙️ **设置检查** | 自动比对交易系统各项设置是否符合标准 |
| 🖥️ **桌面 GUI** | 图形化任务调度、报告中心、批次管理 |

## 🏦 支持的交易客户端

| 客户端 | 菜单数 | 特点 |
|---|---|---|
| 钱龙 | 70 | 基线客户端 |
| 国泰海通 | 70 | 独有「一键炒单设置」 |
| 中泰 | 72/73 | 双层组合申报 |
| 华宝 | 52 | 树拓扑差异较大 |
| 广发 | 57 | 通知查询 6 项专属 |
| 东吴 | 48 | 下单方式嵌在「其他下单方式」 |

客户端切换由 `clients.json` 驱动，菜单别名/重定向自动适配。

## 🚀 快速开始

```powershell
# 1. 安装依赖
python -m pip install -r requirements.txt

# 2. 启动桌面工具
python GUI自动化工具2/main.py
```

> 需要 Windows + 已登录的交易客户端才能执行真实 GUI 自动化。

## 🏗️ 项目结构

```
GUI自动化工具2/     # 桌面 GUI：主窗口、任务中心、报告中心
core/               # 核心引擎：窗口定位、客户端档案、OCR、策略
行情交易/
  ├─ 查询/           # 行情查询（JSON 驱动）
  ├─ 下单/           # 三键/四键/快速下单
  ├─ 撤单/           # 全选撤单
  └─ 组合申报/       # 拆分/组合申报
超级策略/            # 6 种策略一键开仓
交易系统设置/        # 7 面板自动检查 + 标准期望值
tests/               # 单元测试
```

## 🔧 技术栈

- **GUI**：Python 3.12 + Tkinter
- **自动化**：pywinauto / pywin32 / uiautomation
- **OCR**：RapidOCR + ONNX Runtime
- **数据**：pandas / openpyxl / python-calamine
- **打包**：PyInstaller
